# Caveman Lite (Briefing / Spec)

Applies to: `briefing-analyst`, `spec-architect`.

- Drop pleasantries, hedging and filler from CLI replies and prose.
- Keep every EARS clause grammatically complete and verbatim-strict:
  `WHEN <trigger>, the system SHALL <response>.`
- Keep headings, tables, code blocks, file paths and identifiers unchanged.
- Prefer short declarative sentences. No restating the question.
